# 任务卡模板

复制至 `tasks/<任务编号>.md`，任务卡是状态的唯一事实来源。以下占位值必须按真实情况填写，不作为已发生的记录。

## 分配与版本

- 任务编号 / 标题：待填写
- Owner / 实际执行者：codex 或 claude-code
- 角色：implementation / reviewer
- 独立 Reviewer：待填写，不能与实现者相同
- 状态：TODO
- 基线 commit（完整 SHA）：待填写
- 工作区 / 分支：待填写
- 依赖任务：无 / 待填写

## 目标与修改范围

- 目标：待填写
- 允许修改的路径：待填写
- 已授权的接口变化：无 / 待填写
- 交互契约与实施计划：待填写
- 范围外事项：待填写

## 验收条件

- [ ] 可检查的行为或交付条件
- [ ] 相应验证与记录
- [ ] 独立审查及用户验收

## 进度与证据

- 当前结果 / 下一步：待填写
- 实现 commit：待提交 / 完整 SHA
- 交接记录：待填写
- Review 目标与报告：待填写
- 验证命令、日期、环境和结果：待填写
- 风险、设计偏差：待填写
- 阻塞原因及恢复状态：无 / 待填写
- 用户确认与合并 commit：待完成

状态流：TODO → IN_PROGRESS → REVIEW → FIXING／VERIFIED → DONE；阻塞使用 BLOCKED。实现完成但没有可审查提交时保留 IN_PROGRESS 并注明待提交，不标记 VERIFIED 或 DONE。
