# 独立 Review 模板

复制至 `reviews/<任务编号>-<实现短SHA>.md`。只有实际 Reviewer 完成审查后填写结论；实现者不能替对方填“通过”。

## 审查范围

- 任务编号 / Reviewer / 工具：待填写
- Base / Head（完整 SHA）：待填写
- 工作区 / 审查日期：待填写
- 范围和相应交接记录：待填写

## 确认缺陷

| 编号 | 优先级 | 文件与行号 | 影响、证据或复现 | 修复建议 |
|---|---|---|---|---|
| 待填写 | P0 / P1 / P2 / P3 | 待填写 | 待填写 | 待填写 |

没有可行动缺陷时删除占位行并明确说明，不制造发现凑数量。P0 为立即阻断，P1 为高优先级，P2 为正常修复，P3 为低优先级；用户确认阻断项与处理取舍。

## 待验证风险与验证记录

- 尚不能确认为缺陷的疑虑：待填写
- 实际运行命令与结果（PASS / FAIL / NOT RUN）：待填写
- 未覆盖的路径、外部环境与局限：待填写

## 结论与复验

- 结论：待审查 / 需要修复 / 在上述范围内无阻断发现
- 待修事项、复验版本与结果：待填写
- 本结论只绑定上述版本；后续实现变化需更新目标，不自动继承。
