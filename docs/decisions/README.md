# 架构决策记录（ADR）

架构事实见 [架构说明](../architecture.md)，执行范围见 [整体规划](../project-roadmap.md)。此目录在发生重要决策时新增记录，不为凑数量补写未经讨论的决策。

命名：`NNNN-short-title.md`，编号递增且不复用。由提出变更的任务 Owner 编写，Reviewer 核对，用户确认重大取舍；已废弃的 ADR 保留并链接替代记录。

## 当前索引

暂无独立 ADR。已确认的整体方向见项目规划。
